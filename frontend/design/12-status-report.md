# 12 — AI weekly status report

Route `/w/:workspace/reports` and a "Reports" tab in a project · Backend 🕓 (long-running job through BullMQ `ai-heavy` queue, AiJob tracking) · permission `ai:use`

Follow `00-design-system.md`. Paste its Stitch preamble first.

## Behavior notes

- One-click generation. Takes longer than ~15 seconds, so it is **asynchronous**: the user sees a progress card, can leave the page, and gets an in-app notification when it finishes.
- Structured sections: Completed this week, In progress, Blocked items with reasons, Suggested focus for next week.
- The report can be copied, edited and (later) exported; keep an "Export" menu disabled with "Coming soon".

## Prompt

```
Screen set: AI Weekly Status Report for Syntra inside the standard app shell ("Reports" active).

Frame A — Reports index: H1 "Reports", project select "Mobile App ▾", period select "This week (Nov 17–23) ▾", violet filled button "✦ Generate report". Below, a list of past reports as cards/rows: title "Week of Nov 10 — Mobile App", author avatar or a violet sparkle (AI-generated), created time, short summary line "9 completed · 2 blocked", status pill "Ready", and a three-dot menu (Open, Duplicate, Delete).

Frame B — Generating (async): a prominent card with a violet sparkle, "Generating your report…", an indeterminate progress bar and a 3-step checklist with states: "Collecting tasks and comments ✓", "Analyzing progress (in progress)", "Writing the summary". Helper text "This can take up to a minute. You can leave this page — we'll notify you." and a ghost button "Notify me". Also show a toast in the corner "Report ready — View".

Frame C — Report view / editor: two-column. Main column (720px) is a document-style page: title "Weekly status — Mobile App", date range and a "Draft" badge with the violet sparkle "Generated by AI · 4 min ago". Sections with H2 headings and bullet lists:
 - "Completed this week" (6 bullets, each ending with a task id chip),
 - "In progress" (4 bullets with assignee avatars),
 - "Blocked" (3 items in a warning tinted callout with the reason for each: "Waiting on API contract from backend"),
 - "Suggested focus for next week" (3 numbered recommendations).
 Text is inline-editable, with a slim floating formatting toolbar. Right column: a summary card (Completed 6, In progress 4, Blocked 3, Velocity +12% vs last week with a tiny bar chart), buttons "Copy as Markdown" (primary), "Regenerate" (secondary), "Export" (disabled with tooltip "Coming soon"), and a "Share" ghost button.

Frame D — Failed: danger card "Report generation failed" with the reason and "Try again". Frame E — Empty: "No reports yet" with a "Generate your first report" violet button. Frame F — mobile (390px) report view with collapsible sections.
Light theme plus one dark frame of Frame C.
```
